Chia sẻ ứng dụng

App này chạy trong Claude.ai artifact. Để chia sẻ link cho người khác dùng độc lập, cần deploy ra ngoài:

  1. Bấm nút Export trên artifact (góc trên phải)
  2. Tải về file index.html
  3. Kéo thả vào netlify.com/drop → có link ngay trong 30 giây
  4. Hoặc upload lên GitHub → bật Pages → link cố định miễn phí
💡 Khi deploy ra ngoài:
· Người dùng cần nhập OpenRouter key của họ để dùng model phụ
· Tính năng số hóa bằng Claude chỉ hoạt động trong Claude.ai (API key được inject sẵn)
· Lịch sử đề lưu trong localStorage trình duyệt của từng người
